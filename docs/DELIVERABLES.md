# CodeSphere — Submission Deliverables

This page is the handoff index for the project submission.

| Required deliverable | Repository location | What it contains |
|---|---|---|
| Complete source-code repository | Repository root | `backend/`, `frontend/`, Docker files, migrations, and configuration templates |
| Database schema documentation | [database/README.md](database/README.md) | PostgreSQL tables, relationships, and Flyway migration history |
| API documentation | [api/README.md](api/README.md) | Authentication, problem, assessment, session, question, evaluation, reporting, and supporting endpoints; Swagger is available at `/swagger-ui/index.html` while running |
| Architecture/design document | [architecture/README.md](architecture/README.md) | Component diagram, data flows, technology choices, and entity relationships |
| Deployment instructions | [deployment/README.md](deployment/README.md) | Local prerequisites, environment configuration, Docker Compose, and health checks |
| Test cases and testing evidence | [testing/README.md](testing/README.md) | Unit-test coverage, commands, recorded successful checks, and remaining test scope |
| End-to-end demonstration | [DEMO_GUIDE.md](DEMO_GUIDE.md) | A live-demo script spanning admin, candidate, evaluator, result release, and reports |

## Recommended submission order

1. Submit the repository URL.
2. Link this document from the repository README.
3. Use the end-to-end guide for the live demonstration.
4. Keep screenshots or a screen recording as supplemental evidence if required by the instructor.
